## Summary

New standalone repo `opencharly/plugin-crabbox` — the **`crabbox:` check verb**
plugin (candy at `candy/plugin-crabbox/`, served out-of-process over go-plugin
gRPC), mirroring the plugin-openclaw skeleton. Step 2 of the 100%-local
Crabbox×OpenCharly integration (plan/crabbox-integration.md):

- **Three method classes** (all read-only):
  - In-venue CLI **credential-free**: `version`, `providers`, `config`
    (`config show`), `doctor` — probe-verified exit 0 with no broker.
  - **Coordinator HTTP probes** (host-side, port 8080): `health`, `ready` via
    `cc.ResolveEndpoint` + `cc.HTTPDo` → `/v1/health`, `/v1/ready`.
  - In-venue CLI **broker-backed** (require `crabbox login` in the venue):
    `leases` (`crabbox list` — 0.48.x `status` requires an id), `usage`,
    `events` / `logs` (require `run_id`).
- Self-contained `#CrabboxInput` CUE schema, primary `method` sugar, box-mode
  skip, shared sdk verdict pipeline (R3). `plugin_test.go` pins the method
  tables.
- `go build/vet/test` + gofmt clean; `box validate` 0 warnings/0 errors.
